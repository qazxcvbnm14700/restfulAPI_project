# 目的
設計一個本格日式料理線上點餐系統的前端網頁

# 規格需求
- **技術規範**：不使用任何前端框架（使用原生 HTML、CSS、JavaScript）
- **視覺與設計**：
  - 符合高質感日式和風美學（深木色調、櫻花粉與朱紅點綴、優雅字體與精緻卡片式排版）
  - 具備響應式設計（RWD），適應手機、平板與桌面端瀏覽
  - 每個商品皆具備精緻料理實體圖片與微動效
- **功能模組**：
  1. **日式料理菜單與分類展示**：
     - 展示日式人氣主食、經典拉麵、和風定食等豐富品項
     - 每個餐點卡片展示料理實體圖片、品名、簡介、價格
  2. **點擊圖片檢視詳細資訊與專屬副餐**（核心功能）：
     - 使用者點擊料理圖片（或點選查看詳情）時，開啟精緻的「商品詳細資訊彈窗」
     - 彈窗內顯示：
       - 高解析度料理實體大圖與特色標籤（如：人氣 No.1、食材來源、賞味標籤）
       - 完整料理介紹與食材嚴選細節（嚴選食材、產地來源、預估製作時間）
       - **該商品專屬之副餐搭配選擇（每個商品可搭配的副餐選擇不同）**
       - 料理風味客製化選項（如飯量、麵條硬度、湯頭濃淡或蔥花多寡）
       - 數量調整（+ / -）與即時金額計算
       - 「加入購物車」按鈕，點擊後打包該主餐及所勾選之專屬副餐加入清單
  3. **購物車與金額即時計算**：
     - 即時顯示購物車內容，包含所選之主餐、客製風味、各別加選副餐與單項小計
     - 自動計算品項總數與應付總額，支援單項移除與清空購物車
  4. **顧客取餐資料填寫與下單**：
     - 取餐人姓名、連絡電話、用餐方式（內用/外帶/外送）、內用桌號（必填）、外送地址（外送時必填）、備註需求；桌號及地址欄位依用餐方式顯示
     - 點擊「確認送出訂單」後，打包資料送往 `新增訂單 API`
  5. **API 互動與即時反饋**：
     - 畫面載入時呼叫 `商品清單 API (GET /api/menu)` 取得分類及商品卡片資料，動態渲染
     - 使用者點擊商品圖片或詳情按鈕時，呼叫 `商品詳情 API (GET /api/menu/{dishId})` 取得該商品完整資訊、客製選項及專屬副餐；清單 API 不應載入或回傳詳情資料
     - 訂單建立成功後顯示確認畫面與訂單編號
     - 具備「查詢訂單進度」功能，輸入單號即可呼叫 `訂單查詢 API (/api/orders/{orderId})` 取得最新狀態與料理明細
     - 表單防呆驗證（電話格式、內用桌號及外送地址必填、未填資料提示）與送出時的 Loading 載入動畫

# 測試
- 使用瀏覽器開啟頁面，檢查 Console 是否無語法與資源載入錯誤
- 點擊不同料理之圖片，確認能正確彈出對應的詳細資訊，且顯示的副餐搭配各自不同
- 勾選不同副餐與修改客製選項時，金額即時計算正確
- 加入購物車後確認明細包含主餐與個別專屬副餐，總金額加總正確
- 測試送出訂單與查詢訂單功能皆能正常運作
- 測試內用未填桌號時阻止送出；外送時顯示並要求地址，且送出的訂單包含地址；切換至外帶時隱藏並停用桌號及地址欄位
