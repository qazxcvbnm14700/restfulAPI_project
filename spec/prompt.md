# 目的
開發一套本格日式料理線上點餐系統（前後端分離架構）

# 前端規格
讀取 `/spec/frontend.md` 內容並執行

# 後端規格
讀取 `/spec/backend.md` 內容並執行

# 測試
1. 啟動後端伺服器，驗證 `/api/menu`、`/api/orders`、`/api/orders/{orderId}` 各支 API 是否符合 `/spec/backend.md` 的測試要求，並於後端規格書中標記 `[X]`。
2. 開啟瀏覽器訪問前端頁面（`index.html`）：
   - 確認能正常載入日式料理菜單（圖片、品名、簡介、價格）。
   - 點擊料理圖片，確認彈出該商品的詳細資訊（嚴選食材、特色標籤、預估時間等），且副餐搭配依料理各不相同。
   - 進行副餐加選、客製選項調整，檢查即時小計與加入購物車金額計算是否正確。
   - 填寫顧客用餐資訊並按下「確認送出訂單」，檢查是否成功呼叫 API 並顯示產生的訂單編號。
   - 使用「查詢訂單進度」功能查詢訂單，驗證狀態與料理副餐內容。
3. 若測試過程中有任何異常或錯誤，找出原因並自行修正至全部功能測試通過為止。

# 其他
- 測試通過後執行 git commit
- 將 .NET server 的啟動指令寫入 `/run.bat`
